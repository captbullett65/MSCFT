# MSCFT-BIO Example

This example demonstrates how to run the MSCFT-BIO pipeline using a preprocessed gene signal dataset.

## Files in This Example

- processed_data.csv → Cleaned dataset used for GPT analysis

## How to Run

1. Open the file:
   examples/mscft-bio/processed_data.csv

2. Open the MSCFT-BIO GPT:
   (paste your GPT link here)

3. Upload:
   processed_data.csv

4. Open:
   mscft-bio/GPT Template Usage Guide.md

5. Copy the prompt from the **Prompt Template** section

6. Paste it into GPT and run

## Expected Result

The system will return:
- Signal distribution patterns
- Cluster groupings
- Inflection points
- Outliers
